# UTix - Simple React Version

This version keeps the same UI, pages, event data, images, and features, but the React code is written for beginners.

## Run

```bash
npm install
npm run dev
```

## Main React concepts used

- Components: each page and reusable UI part is a component.
- Props: data such as events and tickets is passed from App to pages.
- useState: stores form values, login information, tickets, and search state.
- useEffect: loads events and saves data to localStorage.
- React Router: changes pages without reloading the website.
- map(): displays repeated events, categories, and form options.
- filter(): searches and filters events.
- localStorage: keeps login, tickets, contact messages, and host requests in the browser.

The CSS and public assets are kept from the original project so the visual output remains unchanged.
